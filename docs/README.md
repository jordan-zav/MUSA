# Documentacion publica de MUSA

Solo la documentación revisada expresamente para distribución forma parte de
la documentación pública de MUSA. La ubicación en esta carpeta no autoriza por
sí sola a publicar un archivo local o experimental.

## Archivos principales

| Archivo | Rol |
| --- | --- |
| theory.md | Referencia tecnica del algoritmo global, local, zeta y salidas |
| references.md | Referencias cientificas publicas |
| DEVELOPMENT_STATUS.md | Alcance neutral del software y estado de desarrollo |

Los planes de trabajo, bitacoras de descarga, borradores, paquetes de redaccion y documentos auxiliares no forman parte de la distribucion publica.

Los datos, resultados y entregas de proyectos privados se mantienen fuera
del repositorio. No son productos de MUSA ni material autorizado para ejemplos,
benchmarks o publicación del software. Esta documentación describe métodos,
interfaces y controles sintéticos. Los cambios locales de desarrollo necesitan
revisión antes de considerarse parte de una versión pública.
