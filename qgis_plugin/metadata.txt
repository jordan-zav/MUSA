name=MUSA
description=Fractal and multifractal analysis of fault, fracture and lineament maps, with finite-range scaling checks, in a dockable QGIS workbench.
about=Computes Renyi dimensions and Chhabra-Jensen multifractal spectra of line networks from the exact trace length in each grid cell, averaged over several grid origins. Before reporting an estimate, a finite-range scaling diagnostic declares the scale interval in advance, compares linear, quadratic and segmented fits by cross-validation and labels each result as compatible, not supported or insufficient. An optional Monte Carlo test relocates the observed traces uniformly within the mapped area to check whether their spatial heterogeneity differs from random placement. Also includes global and moving-window spectra, structural statistics, Processing algorithms (musa:analyze, musa:run_recipe) and the same numerical core as the MUSA Python API. Requires NumPy, SciPy, Shapely and Matplotlib in the QGIS Python environment; use a projected CRS in metres.
